# MAX Invite Counter

## Файлы
- `main.py` — бот и подсчёт приглашений.
- `requirements.txt` — Python-зависимости.
- `Dockerfile` — сборка контейнера и установка корневого сертификата Минцифры.

## Настройка Bothost
1. Загрузите все три файла в корень GitHub-репозитория.
2. В переменных окружения Bothost задайте `MAX_TOKEN` — токен MAX-бота.
3. Убедитесь, что постоянная папка данных настроена на `/app/data` (в коде БД уже хранится там).
4. Запустите пересборку Docker-образа.

## Команды в MAX
- `/my` — личное количество добавленных участников.
- `/top` — топ-10 участников.
- `/help` — справка.

Засчитывается событие `user_added` только если `inviter_id` не пустой.
Если участник пришёл по ссылке, MAX передаёт `inviter_id = null`, и приглашение не засчитывается.
Повторные события не дублируют счёт благодаря уникальному ключу `(chat_id, new_user_id)`.

Бот должен быть администратором группового чата, чтобы получать события MAX.
Для чтения команд в группе также нужны соответствующие права чтения сообщений.

## Важно
Проверка TLS не отключается. Docker-образ устанавливает официальный корневой сертификат НУЦ Минцифры с `gu-st.ru`.
Токен храните только в переменной окружения Bothost, не добавляйте его в GitHub.
