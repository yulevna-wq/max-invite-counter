# Счётчик приглашений для MAX

Бот считает, кто сколько участников добавил в группу.

## Правила зачёта
- +1 балл тому, кто добавил участника через «Добавить участников»
- 0 — если человек зашёл по ссылке-приглашению
- 0 — боты, самодобавление, каналы
- повторный вход уже засчитанного человека балл не даёт
- при выходе приглашённого баллы не снимаются

## Команды
- `/my` (или `/моястатистика`) — личный счёт
- `/top` (или `/топ`) — рейтинг TOP-10
- `/help` (или `/помощь`) — правила

## Файлы
- `main.py` — бот
- `requirements.txt` — зависимости
- `Dockerfile` — сборка для Bothost
- `russian_trusted_root_ca_pem.crt` — корневой сертификат Минцифры (обязателен)

## Запуск
Переменная окружения: `MAX_TOKEN` — токен бота с платформы MAX для партнёров.
Данные пишутся в `DATA_DIR` (по умолчанию `/app/data`) — на Bothost этот каталог
сохраняется между деплоями.
